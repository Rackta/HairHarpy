# Можно ли доверять установщику?

*English version: [TRUST.md](TRUST.md)*

HairHarpy делает один человек. Сертификат для подписи кода стоит сотни долларов в год, поэтому установщик и программа
**не подписаны**. Из-за этого при первом запуске Windows SmartScreen пишет «Система Windows защитила ваш компьютер».
Это предупреждение значит «издатель неизвестен», а не «найден вирус».

Верить нам на слово не нужно. Ниже — что можно проверить самому: от быстрой проверки до сборки программы из исходников.

## 1. Проверить, что файл тот самый (1 минута)

Рядом с загрузками каждого релиза лежит файл `SHA256SUMS.txt`. Сравните его с хешем скачанного файла:

```powershell
Get-FileHash "HairHarpy Setup 2.0.0.exe" -Algorithm SHA256
```

Хеш должен в точности совпасть со строкой в `SHA256SUMS.txt`. Если не совпадает — файл изменили или повредили по
дороге, не запускайте его.

## 2. Проверить антивирусами (1 минута)

Загрузите установщик на [VirusTotal](https://www.virustotal.com/): там файл проверяют около 70 антивирусов. В описании
каждого релиза есть ссылка на его отчёт. У неподписанной программы от небольшого автора одно-два срабатывания
малоизвестных движков вида «generic» или «ML» — обычное дело. Срабатывания с названием угрозы у нескольких крупных
антивирусов — нет.

## 3. Ничего не устанавливать: портативная версия

`HairHarpy-<версия>-portable.zip` — та же программа без установщика. Распакуйте куда угодно и запустите
`HairHarpy.exe`. Она не трогает реестр, кроме собственного ключа настроек (см. ниже), и не создаёт ярлыков. Чтобы
удалить — удалите папку и, если хотите, настройки (раздел 5).

## 4. Прочитать код или собрать самому

Весь исходный код — в этом репозитории. Всё, что входит в релиз, собрано из него:

- `src/` — программа (C++ / Qt / Vulkan);
- `installer/src/` — установщик и деинсталлятор (C#, около 600 строк: их легко прочитать целиком);
- `installer/build-installer.ps1` — скрипт, который собирает релиз.

В [BUILDING.md](BUILDING.md) описано, как собрать программу и установщик на своём компьютере бесплатными
инструментами. Своя сборка — это программа, которую вы сделали сами из кода, который можете прочитать. Нашим файлам
тогда доверять вообще не нужно.

## 5. Что установщик и программа делают на компьютере

**Установщик**
- Не требует и не просит прав администратора. Ставит программу в папку в вашем профиле (по умолчанию
  `Документы\HairHarpy`).
- Записывает только:
  - выбранную папку программы (`System\` — программа, её библиотеки, ваши Projects, Presets, Autosaves;
    `Uninstall.exe`; ярлык);
  - ярлык в меню «Пуск» и на рабочем столе, если отмечены галочки;
  - эти ключи реестра, все в разделе вашего пользователя (`HKEY_CURRENT_USER`):
    - `Software\HairHarpy` — папка установки, версия, ваши галочки в установщике;
    - `Software\Microsoft\Windows\CurrentVersion\Uninstall\HairHarpy` — строка в «Установленных приложениях»;
    - `Software\Classes\.hairmesh`, `Software\Classes\HairHarpy.Project`, `Software\Classes\Applications\HairHarpy.exe` —
      открытие проектов `.hairmesh` двойным щелчком, если отмечена галочка.
- Не ставит службы, драйверы, задания планировщика, автозапуск и фоновые процессы. Не трогает системные папки.
- `Uninstall.exe` удаляет папку, ярлыки и ключи выше. Если внутри есть ваши проекты, сначала предупреждает.

**Программа**
- **Не выходит в интернет.** Никакой телеметрии, статистики, проверки обновлений, аккаунтов.
- Единственное сетевое действие — **Bridge → Send**: по нажатию меши уходят по HTTP на `127.0.0.1`, то есть на ваш
  же компьютер, где их принимает дополнение моста в Blender или Maya. С компьютера ничего не уходит.
- Ссылки «About the author», «Support the author» и ссылки в FAQ открываются в браузере **только по щелчку**.
- Запускает другие программы только по вашей команде: RizomUV (по пути, который вы указали) и саму себя (Reload).
- Записывает:
  - сохранённые и экспортированные файлы — туда, куда вы их сохраняете;
  - автосейвы, пресеты и проекты — в `System\` в папке программы (у портативной версии —
    `%APPDATA%\Catarackta\HairHarpy`);
  - свои настройки — в `HKEY_CURRENT_USER\Software\Catarackta\HairHarpy`;
  - файлы обмена с RizomUV — в `%TEMP%\HairHarpy`, когда вы отправляете туда меш;
  - **только пока вы записываете сессию** (кнопка **● Rec**, повторное нажатие — стоп): папку
    `Документы\HairHarpy Sessions\session_<дата>` с журналом сессии — какими инструментами, действиями и кнопками вы
    пользовались, сообщения программы, моменты, когда окно подвисало, имя и путь проекта, камеру, имена и число полигонов
    выделенных и видимых мешей, — и ваши заметки (**✎ Note** / F9): ваш текст и снимок окна программы с вашим рисунком
    поверх. Данные мешей и другие файлы туда не попадают;
  - **если программа упала**: дамп `crash_<время>.dmp` в `Документы\HairHarpy Sessions` (во время записи — в папку
    сессии). Это снимок памяти программы в момент падения, в нём могут оказаться части открытого проекта.

  Ничего из этого программа никуда не отправляет. Папка появляется, только когда в неё что-то записывается; отправлять
  ли папку сессии автору, решаете вы, удалить её можно в любой момент.

**Дополнения моста** (по желанию, `resources/bridge/`) — обычные файлы Python, их можно прочитать до установки.
Дополнение для Blender слушает только `127.0.0.1`. Мост для Maya копирует себя в папку скриптов Maya и добавляет одну
строку в `userSetup.py`, чтобы запускаться вместе с Maya, — об этом написано в начале файла.

## 6. Проверить самому, пока программа работает

Если хочется увидеть своими глазами:
- [Process Monitor](https://learn.microsoft.com/sysinternals/downloads/procmon) показывает каждый файл и ключ реестра,
  которые трогают установщик и программа;
- [TCPView](https://learn.microsoft.com/sysinternals/downloads/tcpview) или «Монитор ресурсов» → «Сеть» показывают,
  что программа не подключается к интернету;
- Брандмауэр Windows может полностью закрыть `HairHarpy.exe` доступ к сети. Программа работает так же, перестаёт
  работать только Bridge → Send (ему нужно локальное соединение с Blender или Maya).

## 7. Linux

Файлы для Linux (`HairHarpy-<версия>-x86_64.AppImage`, `HairHarpy-<версия>-linux-x86_64.tar.gz`) собираются на GitHub
из этого репозитория: [`.github/workflows/linux.yml`](.github/workflows/linux.yml) запускает
`installer/linux/build-linux.sh`. Полный журнал сборки открыт на странице **Actions** репозитория. Хеши проверяются
командой `sha256sum -c SHA256SUMS-linux.txt`.

- Права root не нужны ни для того, ни для другого. **AppImage** — программа одним файлом: запустите его; чтобы удалить,
  удалите файл.
- **tar.gz** — та же программа папкой. Её `install.sh` (короткий скрипт, прочитайте его сначала) пишет только: папку
  программы (по умолчанию `~/.local/share/HairHarpy`), пункт меню `~/.local/share/applications/hairharpy.desktop`, его
  значок `~/.local/share/icons/hicolor/256x256/apps/hairharpy.png` и, чтобы открывать файлы `.hairmesh`,
  `~/.local/share/mime/packages/hairharpy.xml`. `uninstall.sh` удаляет ровно это.
- Программа ведёт себя, как описано в разделе 5, только места в Linux свои: настройки — `~/.config/Catarackta/HairHarpy.conf`;
  проекты, пресеты и автосейвы — `~/.local/share/Catarackta/HairHarpy`; файлы обмена с RizomUV — `/tmp/HairHarpy`;
  записи сессий — `~/Documents/HairHarpy Sessions`. Дампы падений сборка для Linux не пишет.
- Проверить самому: `strace -f -e trace=network` или `ss -tp` покажут, что единственное соединение программы — мост на
  `127.0.0.1`.
